# M-OS

M-OS is a personal management system written in C.

## Features

- Personal Library
- Task Manager
- Notes
- Finance Tracker
- Personal Planner
- Binary File Storage
- Input Validation

## Technologies

- C
- Standard C Library
- Binary File I/O

## What I Learned

- Structures
- Arrays
- Functions
- Pointers
- Dynamic Memory Allocation
- File Handling
- Binary Files
- Input Validation
- Modular Programming
